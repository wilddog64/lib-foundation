# Retrospective — v0.4.17

**Date:** 2026-09-12
**Milestone:** ACG session/credential reliability — close out the lib-acg archive
**PR:** #51 — merged to main (`92d885272daeae411dc62e7226ffe84c3986f557`)
**Also shipped in this arc:** #48 (v0.4.16), #49, #50
**Participants:** Claude, Copilot

## What Went Well

- **Triaging the retired repo's open PR paid off.** lib-acg #47 was diffed half-by-half
  instead of assumed absorbed. One half (`_sts_valid`) was already fixed here; the other
  (the `.psPrismAvatar .psPrismMonogram[aria-label]` selector) had never been ported and
  would have been lost when the repo was archived.
- **Every fix in this release is grounded in a live measurement, not a reading of the code.**
  `id.pluralsight.com` was confirmed dead by `dig`/`curl`; the profile split-brain was
  quantified as 0 vs 34 cookies; the STS misdiagnosis was proven by a direct SigV4 call
  succeeding with the same credentials the CLI could not use. Each one is written up in
  `docs/bugs/` with the evidence.
- **A destructive failure path was found by asking why a probe deleted something.** The
  `acg-credential-test` STS probe keyed on exit status alone, so "the aws binary cannot
  start" and "STS rejected these credentials" were the same signal — and only the second
  justifies delete-and-restart. The restart was futile by construction.
- **Release notes are the CHANGE.md section verbatim.** No hand-written summary drifted from
  what shipped.

## What Went Wrong

- **A real credential leak sat unfixed for three months because a doc deferred it to a repo
  nobody shipped from.** k3d-manager's PR #91 Copilot finding parked `gcp.js` logging
  `username.slice(0, 30)` as "lib-acg upstream debt". Archiving lib-acg stranded that
  routing. Fixed here as #49.
- **The CHANGE.md rebase damage on #50 was caused by my own conflict resolution**, not by
  the tooling. It was caught by Copilot, not by me.
- **The verbatim tree-copy in v0.4.0 silently inherited the source repo's package
  identity.** `package.json`/`package-lock.json` still read `"name": "lib-acg"` five
  releases later. Not in this release: the fix and its spec
  (`docs/bugs/2026-09-12-acg-package-name-still-lib-acg.md`) are both queued on the
  unmerged branch `fix/acg-package-name-identity`, so neither is on `main` yet.
- **The live `make credential-test PROVIDER=aws` gate still has not run green.** #50 fixed
  what the 2026-09-12 failure was actually caused by, but the gate needs CDP on :9222 plus a
  one-time manual Pluralsight login, so the release shipped on offline gates only.
- **Four prior releases (v0.4.13–v0.4.16) have no retro.** This document resumes the practice
  rather than back-filling them.

## Process Rules Added

| Rule | Where it came from |
|------|--------------------|
| When deprecating a repo, grep every doc that defers work to it and re-point it — archiving strands the deferral, not just the code | The `gcp.js` leak sitting for three months |
| Triage every open PR of a repo into a carry-forward doc *before* archiving it | lib-acg #47's unported selector half |
| Historical references to a retired repo are provenance — do not "correct" them | 89 `lib-acg` references; only 3 were live metadata |
| A repo absorption checklist must include an explicit "re-home the package metadata" step | `"name": "lib-acg"` surviving the tree-copy |
| Never verify a rebase with the conflicted file excluded — use a positive assertion | #50's CHANGE.md rebase damage |
| A probe that can delete something must distinguish "tool broken" from "answer is no" | The STS probe destroying a live sandbox |

## Decisions Made

- **Never delete or migrate `~/.local/share/k3d-manager/profile` or `pw-profile`.** The
  `Identity.Session` cookie is non-persistent, so the login lives exactly as long as the
  Chrome process; destroying a profile destroys a session that cannot be scripted back.
  `PLAYWRIGHT_AUTH_DIR` was re-pointed, not consolidated.
- **Installing the `com.k3d-manager.chrome-cdp` launchd agent stays a manual operator step.**
  `launchctl load`/`bootstrap`/`unload` is explicitly out of scope for any agent.
- **The dropped `text=/Cloud Sandboxes/i` / `text=/Open Sandbox/i` markers are not coming
  back.** They describe page content, not identity. The Prism monogram is the identity
  signal; signed-out is now detected positively rather than inferred from absence.
- **The package rename ships separately.** Holding it out kept its diff to exactly three
  identity lines and kept it off the release's critical path.

## Theme

This release is the bill for retiring a repository. Archiving `wilddog64/lib-acg` was one API
call, but the work it actually implied was finding everything that still pointed at it — an
unmerged PR half, a Copilot finding parked as "upstream debt", a package name, eighty-nine
documentation references — and deciding, one at a time, which of those were stale and which
were history worth keeping. Underneath that, the ACG automation turned out to be failing for
reasons nobody had measured: waiting five minutes on a hostname that no longer resolves,
authenticating against a profile with no cookies in it, and deleting live sandboxes because a
Homebrew ABI mismatch looked exactly like a rejected credential. None of those were visible
from reading the code; all of them were obvious the moment something was actually run. The
release closes the archive and fixes what the archive was hiding.
