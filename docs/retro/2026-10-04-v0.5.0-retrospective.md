## Decisions Made

- Python test-file detection is a configurable glob list (`AGENT_AUDIT_PY_TEST_GLOB`), split with
  `read -r -a` so it never glob-expands against the working directory.
- The syntax check compiles the staged blob, never the working-tree file, and skips with a warning (not a
  failure) when the interpreter is missing.
- A dangerous-call exemption needs a reason: `# agent-audit: allow <rule> <reason>`.
- Known edge, accepted: a whitespace-only `AGENT_AUDIT_PY_TEST_GLOB` errors under Bash 3.2 `set -u`.

## Theme

k3d-manager now has about 74 Python files and 420 Python tests, and the commit-time audit saw none of them.
v0.5.0 gives Python the same guard the BATS suites already had: an agent cannot quietly delete a test, weaken
an assertion, commit a syntax error, or add `shell=True` without saying why. k3d-manager adopts it next, in
a subtree pull alongside the remaining python-agent-rigor milestones.
